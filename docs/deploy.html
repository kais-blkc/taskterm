taskterm: деплой

Docker запускает проект и отдаёт порт 3100. Nginx настраивается отдельно на хосте.

Что запускается

КонтейнерЧто этоПорт
appAPI + собранный фронт3100 (наружу)
dbPostgreSQL 17, том taskterm-pgне публикуется

Нужно: Docker и плагин compose (docker compose version).

Запуск

cd /opt/taskterm                 # куда загружен проект
cp .env.example .env
nano .env                        # см. ниже
docker compose up -d --build
docker compose ps                # app должен стать healthy
curl http://127.0.0.1:3100/api/health

Миграции БД применяются при старте. Контейнеры сами поднимаются после перезагрузки сервера.

Nginx

Проксировать всё на 127.0.0.1:3100:

location / {
    proxy_pass http://127.0.0.1:3100;
    proxy_http_version 1.1;
    proxy_set_header Host $host;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
    proxy_buffering off;         # живые обновления (SSE, /api/events)
    proxy_read_timeout 1h;
}
Host передавать как есть: приложение сверяет Origin с Host (защита от CSRF). Если домен отличается, добавь его в ALLOWED_ORIGINS.

Первый вход

Войти как ADMIN_USERNAME. Регистрации на странице входа нет: в разделе admin создаются приглашения, ссылку /register?token=… админ отправляет человеку сам. После первого входа ADMIN_PASSWORD можно убрать из .env.

Обновление

# обновить код, затем:
docker compose up -d --build

Данные в томе сохраняются.
